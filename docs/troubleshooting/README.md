# 트러블슈팅 기록

쿠폰 동시성 테스트와 전체 테스트 실행 결과에서 확인한 현상을 원인, 대응, 검증 결과 순서로 정리합니다. 각 문서는 현재 확인한 범위와 남은 과제를 구분합니다.

| 문서 | 살펴본 문제 | 상태 |
| --- | --- | --- |
| [TS-001: 초과 발급은 없는데 낙관적 락 충돌로 요청이 실패하는 이유](001-optimistic-lock-conflict.md) | 데이터 정합성과 요청 실패 사유를 구분하고 Redis 락 적용 경로와 비교합니다. | 분석 및 비교 검증 완료 |
| [TS-002: Testcontainers를 사용하는데 contextLoads가 로컬 DB에 연결하는 이유](002-testcontainers-context-load.md) | 테스트별 데이터베이스 설정 차이로 발생한 전체 테스트 실패를 분석합니다. | 원인 확인 · 개선 예정 |

두 기록은 기존 테스트 코드와 저장된 테스트 보고서를 근거로 작성했습니다. 보고서의 실행 범위와 결과는 [테스트 검증 기록](../testing.md)에서 확인할 수 있습니다.

각 문서는 `문제 상황 → 원인 분석 → 대응과 검증 → 배운 점 → 남은 과제 → 관련 코드와 테스트` 순서로 작성합니다. 기술 선택의 이유는 [ADR](../adr/README.md)에, 전체 기능과 실행 방법은 [프로젝트 README](../../README.md)에 정리합니다.
